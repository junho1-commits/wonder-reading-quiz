# 내 컴퓨터에서 음성 포함 영상 만들기

필요한 것: **파이썬 3**, **ffmpeg** (둘 다 명령어로 실행 가능해야 함)

1. 이 저장소를 내려받습니다. (`git pull` 또는 ZIP 다운로드)
2. `video` 폴더에서 아래를 실행합니다.
   ```
   python add_voice.py
   ```
3. `video/원더_골든벨_사용법_음성.mp4` 가 만들어집니다. (약 3분)

## 동작
- `audio_urls.json` 의 음성 14개를 `video/audio/` 에 내려받습니다. 이미 있는 파일은 건너뜁니다.
- `frames/` 의 자막 프레임에 음성을 입히고, 음성이 장면보다 길면 장면 길이를 늘립니다. (음성 뒤 1.2초 여유)

## 음성을 바꾸고 싶다면
- `audio/00.mp3` … `12.mp3`, `99.mp3` 를 다른 음성 파일로 덮어쓴 뒤 다시 실행하세요. (파일명 번호는 장면 번호)
- 장면 번호와 대본은 `typecast_대본.txt` 에 있습니다.

## 참고
- `audio_urls.json` 의 주소는 생성 서비스의 임시 저장 주소라 시간이 지나면 열리지 않을 수 있습니다. 그때는 음성을 새로 생성하거나 mp3를 직접 `audio/` 에 넣어 주세요.
- 화면(자막 프레임)을 다시 만들려면 `capture.js`, `compose.js` 를 쓰며 Node.js와 Playwright가 필요합니다. 음성만 바꾸는 경우에는 필요 없습니다.
