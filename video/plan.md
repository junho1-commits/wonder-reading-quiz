# 원더 독서 골든벨 사용 설명 영상 — 계획

## 목적
다른 교사가 영상만 보고 앱을 직접 운영할 수 있게 한다.

## 범위 (사용자 확정)
- 화면 모형이 아닌 **실제 teacher.html / student.html 화면**을 녹화 (모형 대신 실제 앱 재사용)
- 교사: 화면 열기, 방 코드·QR, 퀴즈 세트 선택, 문제 진행, 정답 공개, 종료
- 학생: 접속, 학반번호·이름 입력, 대기실, 문제 풀이, 결과
- 형식: 한글 자막이 들어간 mp4 (음성 없음)
- 제외: 구글시트 연동, 문제 점검/주의사항 (필요하면 후속 작업)

## 제작 방식
1. Playwright(Chromium)로 교사·학생 페이지를 같은 브라우저 컨텍스트에서 열기
2. 외부 의존성은 로컬로 대체 (샌드박스에서 CDN과 MQTT 브로커 접속 불가)
   - mqtt → 같은 브라우저 안 BroadcastChannel 기반 가짜 버스 (앱 코드는 수정하지 않음)
   - qrcodejs, SUIT 글꼴 → npm 패키지로 대체
3. 장면별 스크린샷(교사 화면 + 학생 폰 화면 나란히) 캡처
4. 장면마다 한글 자막·단계 번호를 입힌 프레임 합성
5. ffmpeg로 mp4 합성
